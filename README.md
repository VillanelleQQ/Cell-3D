# 细胞三维展示

参考 `../细胞.jpg` 的植物细胞与动物细胞教学模型。所有前端依赖在 `vendor/`，浏览器访问不依赖外部 CDN。服务仅提供 `viewer/` 下的文件和原始参考图，不提供研究源码目录的浏览。

## 启动及访问

在服务器执行：

```bash
cd /network_space/server129/tangqianqian/project/Cell
python viewer/serve.py --start --port 8765
```

服务以后台进程运行，监听 `0.0.0.0`。重复运行启动命令会返回已运行的服务；指定端口被其他服务占用时，会尝试后续端口，实际端口记录在 `viewer/server.json`。

本次部署地址：`http://222.29.51.126:8765`。该地址在当前服务器本地可响应；客户端能否直连取决于网络连通性。无需为查看模型调整防火墙，可采用已有 SSH 连接的端口转发。

在自己的电脑执行，SSH 用户名、端口和主机应与已有服务器连接一致：

```bash
ssh -N -L 8765:127.0.0.1:8765 YOUR_USER@222.29.51.126
```

随后在本机浏览器访问 `http://127.0.0.1:8765`。也可以在 VS Code 的“端口”面板转发服务器端口 `8765`。若本机端口已占用，改为 `-L 8766:127.0.0.1:8765` 并访问本机 `8766`。

查看状态与日志：

```bash
python viewer/serve.py --status
tail -n 50 viewer/server.log
```

本次后台进程运行状态保存在 `server.json`。它不是系统开机自启服务；机器重启后需要再次执行启动命令。

## 交互与模型

- 旋转模式：鼠标拖动旋转，滚轮缩放，右键拖动平移；触屏单指旋转、双指缩放/平移。
- 移动模式：拖动细胞中的可见结构，移动整个细胞；先在结构列表中选中一个细胞器，再拖动同一个细胞器，可移动该部件。
- 勾选控制部件显隐；结构名称选择部件并显示信息。工具栏提供复位、自动旋转和导出。
- 外壳透明度作用于植物细胞壁/细胞膜和动物细胞膜；拆分滑块将内部部件展开。复位恢复模型位置、拆分和相机位置。
- 每个细胞包含 12 组有名称的结构。植物细胞具有细胞壁、中央液泡及叶绿体；动物细胞包含溶酶体、中心体及小囊泡。
- `models/plant-cells.glb`、`animal-cells.glb`、`both-cells.glb` 是已经导出的模型，可用支持 glTF 2.0 的软件打开。网页导出会保留当前显隐状态与部件位置。

模型通过 `app.js` 的分部件几何生成，可调整位置、颜色、形状及数量。GLB 包含独立命名节点，便于后续编辑。核膜剖面、膜性囊体及线粒体嵴等为简化教学几何，不代表真实细胞的测量结果。

## 验证

真实 Chromium 浏览器验证覆盖：桌面/手机渲染、画布彩色像素、鼠标旋转、整细胞与部件拖动、复位、显隐、选中、滑块、自动旋转、参考图加载和三份 GLB 导出。已检查 GLB 文件头、长度、网格及结构命名。结果位于 `verification/report.json`，截图同目录。

浏览器验证工具安装在工作区临时目录，服务运行只需要 Python 标准库。复现验证：

```bash
cd /network_space/server129/tangqianqian
PYTHONPATH=tmp/cell-preview PLAYWRIGHT_BROWSERS_PATH=/tmp/cell-playwright-browsers python project/Cell/viewer/verify_viewer.py
```

临时浏览器缓存若被清理，需要先重新安装 Playwright 的 Chromium。GPU 推理没有参与本次建模。
